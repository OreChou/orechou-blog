## 洞见 - Insights

### ChatGPT & Codex 合并
上周四 OpenAI 家的桌面版 ChatGPT 和 Codex 两个 app 合并了，先前是手机端的 ChatGPT 放入了 Codex，现在桌面版的也合并了。现在老桌面 ChatGPT 应用更新之后显示叫 ChatGPT Classic，而 Codex 更新之后直接就叫 ChatGPT 了。

这两个入口的合并对于 OpenAI 企业和用户都是好事。对于企业来说品牌统一回 ChatGPT，可以利用回 ChatGPT 的传播广泛度吸引到那些只知道 ChatGPT 用户接触、使用 Coding Agent 的功能。对于用户来说，少了一个入口，就是简化了操作。而且在现在 Chat 应用泛滥的 2026 年，老 ChatGPT 应用确实是比较鸡肋了。

### Musk 的开源
这周，Musk 前后分别宣布开源 X（也就是之前的 twitter），以及 Grok build 的源代码。前者应该是之前一直作出的承诺？后者则是对 Grok 拉取用户代码舆论的应对。

先前 SpaceX 花 600 亿收购 Cursor，当时觉得 Musk 买亏了，现在觉得 Musk 真是厉害。因为 Coding Agent 就是现在 AI 应用的最通用场景，而 Cursor 应该是最早的 Coding Agent 产品，积累了很多的用户使用数据。其实挺希望 Grok 能做好，让我们在 OpenAI、Anthropic 之外还能有比较好的选择。

### Apple Intelligence 备案成功
Apple 在画饼三年之后，终于可能能够让中国用户使用上 Apple Intelligence 了。如果没有其他意外的话，应该是在 iOS 27 的版本提供支持。

海外的大部分服务要在中国能够使用。有一系列的合规、内容审查。比如模型不能输出违规内容，要通过系统性的意识形态以及内容安全的评估。那么这带来的问题就是海外的模型肯定是不能用了，要找国内供应商做替换，Apple 就和阿里千问达成了合作。这个消息一公布，也是周三阿里股价上涨的原因。

## 器物 - Artifacts

### Sid Meier's Civilization VII
最近玩上了《文明7》。两个周末，22 小时，完成了一局军事胜利。一如既往，文明开一局，下一回合就到第二天了。

![](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/civilization_VII_1.jpg)

玩下来，我感觉很明显《文明7》是要比《文明6》好玩的。我有几个主观感受：
1. 定居点有城市和城镇的区别，城镇作为城市的附属，城镇可以花钱转换成城市。这大大降低了后期游戏后勤的操作琐事。在《文明6》后期的每个回合里面二三十座城，每个城市都要去点，这受得了么？
2. 战斗更容易控制了。部队不需要升级了，然后指挥官可以升级。这显然更合理好么？《文明6》的指挥官只能给部队升级用一次，这什么玩意儿。现在的指挥官可以吸纳部队，开拔战场，然后在部署战队。也是大大降低了战斗的控制复杂度。舰队可以进入河流，非常合理。
3. 美术和上一代有一些改进。虽然我感受不出来太多，两者的美术风格是一致的。有时候我也会把文明当成一个建筑游戏，欣赏里面的建筑。😂。

## 情绪 - Sentiments

### Lionel Messi
我印象中最早看的球是中超，第一次看的世界杯是 06 年。从那以后基本每届世界杯都看过。虽然不是每场，但基本重要的比赛都看了，要么看的直播、要么看的回放。我还记得 06 年梅西在世界杯初登场时，解说的那句“小将梅西”。

2022 年卡塔尔世界杯 Messi 率队夺冠。他拿到了世界杯冠军这个最后的荣誉拼图，成为了全满贯的足球运动员（他获得了所有能够参加的赛事的所有冠军，甚至两次获得代表体育最高荣誉的劳伦斯奖），成为了 Goat（Greatest Of All Time）。

虽然 Goat 这个称号，在当时可能还会有些争议，因为存在世界杯三冠的球王贝利。但是这届世界杯之后，Goat 基本没有任何争议了。只要了解足球基本知识，看过一些比赛，基本都会认可这个结论。这里放一个梅西在本场杯赛的数据图，可以看出他一个人顶一支球队的攻击线，数据是多么的炸裂。然而这是已经离开了五大联赛，在美职联养老的 39 岁的 Messi。

![](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/lionel_messi_in_world_cup.jpeg)

这届杯赛之后，他已经不是球王，是球神。他就是这个运动的本身，代表着最纯粹的足球。

另外。谈谈 Messi 和 C 罗。他俩的竞争是过去，以及现在一直被人们提及的话题。之前说他俩是绝代双骄。我的看法是在 18 年之前，他们确实是在某种程度上的绝代双骄，但其背后是巴塞罗那和皇家马德里的竞争。两位运动员离开了各自职业生涯最重要的俱乐部之后，两个球员的价值才真正的被外界看到。而我们看到的是 Messi 成为足球之神的颠沛流离，以及 C 罗成为极致利己的足球偏执狂。

### 梦境
昨晚做了一个梦，梦充满想象力，以及电影感。所以我将其记录在这里，万一后面能写个剧本呢。

我身处一个未知的国度。正在一个中央汽车枢纽站排队等车，突然发现排在我前面的那个人拿着刀，想要上车之后了捅人。犹豫之后，我决定跟着他上车，在他下手之前大喊“你在干什么！”，大家都看到持刀者引发了混乱。我在混乱中下车，发现了一件震惊的事情，所有的车都有发了疯的持刀人在行凶。

梦境中出现四处的尖叫以及杀戮的场面，人人自危（有电影《生化危机》第二部的画面感）。

随后我躲进了一个官方机构，原来我是一个侦探，开始协助官方做调查。在调查的过程中，我无意间发现了机构里面被安置了监听器。我通过监听器发现了一个组织，并与其取得联系，随后约定了见面地点。在一个夜晚，画面中心是一个点着火的汽油桶，四周围着一群持有武器装备的人。这就是约见的地点。经过交谈知道了他们不是暴乱组织，而是自由组织。而他们的目的就是进入航空基地坐上宇宙航班，离开这个国度，获得自由。而我因为有官方背书，是一个比较好的飞船潜入对象，于是交给我的任务就是协助他们帮助一个人进入飞船离开。

行动开始之前我遇到了爱人，我告诉她这个国度有问题，去坐宇宙飞船离开，我会在那里等她。我带着一名自由组织人员开始进入，这里开始有电影《雪国列车》的画面感，我们进入很长的通道连廊，每过一个连廊都要打开一个门。就在快要到达终点的时候，后方传来了爆炸和警报，在紧急之中，我和另一位组织人员终于打开了最后一扇门进入了飞船。飞船是碟形的，里面坐满了权贵，纸醉金迷。我走到窗边焦急地等待爱人，而她居然神奇出现了。我拥抱她。这个期间有极大的焦虑以及满足释怀感。而此刻飞船立刻起飞，贴着地面不高开始飞行。我们从而看到了暴乱的军队在攻击航空基地的场景，很多人中单倒地。那名自由组织人员说他们将会在 2 天之内攻下这里或者全部死亡。

飞船开始加速，贴着海面，飞过高山，越来越快，快到仿佛在时空隧道里面飞行。随后窗外出现了中东的佩特拉古城，埃及的金字塔、狮身人面像，以及我已经遗忘了的古迹。最后旱地直拔，冲出了地球......
