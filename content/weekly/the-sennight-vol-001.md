《七日书》。我即将开启的周刊系列的刊名，言简意赅的名字，记录一周 7 日之中的点滴。英文名《The Sennight》，七个夜晚，望有些许诗意。

我很喜欢写文字这件事情，虽然我并不擅长。但我觉得一个人，如果能写自己喜欢的文字，输出想要输出的内容，是一件很开心的事情。所以我要成为一个开心的人。我写的文字并不好阅读，但所有的文字均会从我指尖敲出，产生于我这颗人脑。可放心不会是大语言模型生成。

## 洞见 - Insights

### 《揭秘日》
我一直对 UAP、UFO、alian 保持好奇心，所以近期去看了《揭秘日》这部电影。

没看之前的期待过高，看完之后就没有了二刷的欲望。谈谈自己的主观感受：
1. 剧情冲突有些不合理。例如男主多次从机构的抓捕中逃脱，都太过于不合乎情理。（这可能和我已经变成了中登有关，太在乎剧情的逻辑性、合理性）
2. 电影里面的信息密度不大。提到的那些 alian 内容基本上我是知道，所以我没有太多的惊喜。
3. 对我来说精彩的内容是电影的最后 10 分钟。那些亦真亦假的 UFO 和 alian 不才是一个外星题材电影里面需要有份量的内容么？

对于大洋彼岸掀起的大揭秘运动中，这部电影的目的是什么呢。是幻想？是预言？还是预告？我期待它是预告吧。

## 器物 - Artifacts

### Atoll
发现了一个颜值高、功能好、安装简单并且免费的 macOS 应用，[Atoll](https://getatoll.app/)（环礁）。这是一个围绕着 macOS 的刘海打造的灵动岛应用，但这个应用名称取得实在是非常精妙。
![Atoll](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/atoll.jpeg)
它的功能非常丰富：
1. 控制音乐查看日程；
2. 打开番茄时钟；
3. AirDrop 快速分享；
4. 打开命令行，查看内存、CPU 等占用；
5. 提取桌面像素颜色、展示历史粘贴板；

我现在十分喜欢这个免费软件。

## 情绪 - Sentiments

### AI 驾驶员
过了 7 月 1 号，突然发现已经工作了 7 年了。简单谈谈我现在的工作，我愿称现在的工作为：AI 驾驶员。

之前我是一个程序员，工作的主要目标是将公司的产品需求翻译成工程化的代码，保证其可靠性、稳定性、可维护性。工作方式是用我的大脑知识去做技术方案、编写代码。

而现在工作目标是一致的，但是工作方式已经发生了很大的变化，几乎所有的内容实现都是通过 AI 工具来实现。这里的 AI 主要指 Coding Agent 搭配上各种 Skill 或者软件工具提供的 MCP 或者 cli 入口。例如：
1. 产品原型设计：Pencil MCP
2. 文档编写、流程规划：Superpowers
3. 编码、测试、提交：Codex、Claude Code

我掌握着 AI 的方向盘，力求快速、高质量地把需求落地。几个月来，不止是我，很多程序员都转换得很快。

不过这个过程中，我发现了一些有意思的地方：
1. 需求变多。这很正常，AI 加速了绝大部份程序员的效率。单位时间干得越多，干得事情也就会越多。
2. 质量下降。这也可以理解，随着项目中产品经理或者测试参与 Vibe Coding，工程质量不可避免地下降。这里面包含过度设计、缺乏设计的各种实现。
3. token 账单。团队的管理在最开始提倡开始多使用 token，到后面账单崩不住，开始提倡有效使用 token。

现在编码已经变成了一种 easy cheap 的事，没有门栏。但AI 驾驶的好不好也慢慢变成衡量一个程序员的指标。

希望大家能从编码之后抽身，并投身于创造。

### 世界杯
这周开始， 26 年世界杯进入了淘汰赛阶段，本周末看了两场。

第一场是葡萄牙对阵克罗地亚。C 罗踢进一个点球，终于拿到了世界杯淘汰赛里面的第一个进球，然后 Ramos 的头球帮助葡萄牙晋级。赛后 C 罗也拿到了 MVP。遗憾克罗地亚和魔笛，这真是魔笛最后一场世界杯比赛了，而失去魔笛的克罗地亚在未来的世界舞台上也不知道是否能重焕光芒。

第二场是阿根廷对阵佛得角。阿根廷的比赛是非常好看的，两度领先，两度被人口只有 50w 的非洲小国追平。这就是足球的魅力，这也是世界杯淘汰赛的魅力。不管你是世界冠军，还是普通球队，在淘汰赛的每场战场上只有拼命战斗，才能走到下一场。而梅西，这个足球里面作为神的存在。在比赛中接中场长传小角度首开破门，到最后的角球助攻破门，一球一足。如果不是梅西，卫冕冠军就在这届赛事里面被大黑马佛得角掀翻了。赛后我去看了下佛得角在哪里，下面是 Google 地图里面的定位：
![Cabo Verde](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cabo_verde.PNG)

我本以为佛得角在非洲大陆上，结果是大西洋上的 10 个火山岛。给予佛得角以及门将沃齐尼亚（Vozinha）最高的尊敬🫡。
