今年年初的时候为了使用 OpenClaw，我翻出了 10 年前的两台 MacBook 来折腾。作为爆火的现象级 Agent 产品，OpenClaw 从大洋彼岸红到了国内，火到一波无意义的焦虑在国内散播。之后也折腾了 Hermes。但用下来总觉得差强人意，需要去搞一堆复杂的配置，选模型，选技能等等。

用得越多，越觉得大道至简。产品不是让大家用复杂的东西，而上述的 OpenClaw 并不好用，Hermes 也是如此。

现在我的观点是：作为个人 Agent 的搭建，CC 或者 Codex 组合 Skills 是无敌的存在，是无敌。那么如何将 CC 和 Codex 集成到你的 Agent 团队中，其实一个软件就可以了。它就是 Cumora，作者是大佬 yetone。

## 我的 Agent 团队

下面的就是我的 Agent 团队，一共 6 个，涉及到产品研发以及金融投资。

![Cumora Agent](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-agent.png)

非常舒服的页面，Agent 员工洁面明了。而每一个 Agent 员工可以分配到独立的 CC 或者 Codex 实例上。如下：

![Cumora Agent Setting](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-agent-setting.png)

你所需要做的，只是给你的 Agent 定义角色（这里需要需要设计角色的提示词）。因为底层是 CC 和 Codex，它可以自己去寻找它所需要的 Skill，或者你主动安装一些好玩的 Skill，例如 opencli。hhh。

每个 Agent 都有自己的个性、记忆、状态，它为你服务的过程中也在自我“成长”。

## 让 Agent 来玩一场狼人杀吧

为了测试可玩性。我直接在大群的群聊里面让 Agent 来玩一场狼人杀。于是充当法官的 Agent 开始组织游戏，群里开始轮流发言：

![Cumora Werewolf](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-werewolf-1.png)

以及法官私聊每个 Agent 进行游戏，刀人、查验等：

![Cumora Werewolf](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-werewolf-2.png)

说实话，当狼人杀玩起来的时候，有惊讶到我，让我感觉到了我的 Agent 员工们的活人感，这或许就是未来的世界。

现在各种开各种会议的时候，我都在想为什么不能把我的 Agent 拉进会议代替我。它可以完全可以接入我的数据，克隆我的声音。我很期待所有 IM 开放的那天。

## 干点实际的活

分配工程代码任务。有 Agent 做调研、有 Agent 写代码、有 Agent 管进度。有一种这就是当老板的爽感（先不谈效果、以及你需要监督审查干活的质量）：
![Cumora Coding](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-coding.png)

我甚至可以在日历上安排任务，让某个 Agent 在某个时间同步内容给我：
![Cumora Agent Event](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-agent-event.png)

在投资上，安排做投资调研的任务：
![Cumora Invest](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cumora-invest.png)

而下一步，我会让他接入富途的 API，参与自动化交易。

这一切的一切，非常的简单。这就是产品的 taste，以及加上强大的模型。

## 最后

如上，搭建你的 Agent 团队，只需要 CC 或者 Codex，以及 Cumora。

唯一要担心的，只是你的 token 账单。
![Token fired](https://orechou.oss-cn-shenzhen.aliyuncs.com/images/cc-switch-token.jpeg)

祝大家玩得愉快。
